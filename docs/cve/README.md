# CVE 挑拣记录

每月一份 `YYYY-MM.md`，记录当月评估过的 CVE。

流程说明见 [../cve-process.md](../cve-process.md)。

## 字段

| 字段 | 说明 |
|---|---|
| CVE | 编号 |
| 子系统 | `fs/f2fs`、`net/`、`binder`、`mm/` 等 |
| 影响面 | 提权 / 越界读 / UAF / DoS |
| 上游修复 | 上游 commit 或 stable tag |
| 本地状态 | 已移植 / 不适用 / 待评估 / 放弃 |
| 本地 commit | 移植提交 |
| 验证 | 编译、开机、回归结果 |
